## 1. Five prompt lines that stop Claude writing a fluffy README

```
Tell Claude what the tool does, how to install it and how to run it. Then add: Use only these facts.
```

## 2. Five prompt lines that stop Claude writing a fluffy README

```
Paste: No emojis. Do not use the words powerful, blazing, effortless, robust or lightweight.
```

## 3. Five prompt lines that stop Claude writing a fluffy README

```
Paste: Sections in this order: Install, Use, Options, Limits. Nothing else. Under 200 words.
```

## 4. Five prompt lines that stop Claude writing a fluffy README

```
Paste: Do not invent features, numbers or a license. If something is missing, write TODO.
```

## 5. Five prompt lines that stop Claude writing a fluffy README

```
Paste the README and your facts back in: List every sentence you cannot trace to these facts, one line each.
```

## 6. A one-line ask versus a prompt with facts when you want an AI to write an instruction file

```
Write a CLAUDE md file for my project.

The AI has no facts about your project, so it guesses.
```

## 7. A one-line ask versus a prompt with facts when you want an AI to write an instruction file

```
Paste: Stack: Python 3.12, Flask, pytest, ruff. Commands: pytest -q and ruff check . Hard rule: money is stored as integer cents, never floats.
```

## 8. A one-line ask versus a prompt with facts when you want an AI to write an instruction file

```
Paste: Under 40 lines. No advice like write clean code. If you need a fact I did not give you, write TODO instead of guessing.
```
