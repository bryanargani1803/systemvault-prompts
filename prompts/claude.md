## 1. Five prompt lines that stop Claude writing a fluffy README

```
Tell Claude what the tool does, how to install it and how to run it. Then add: Use only these facts.
```

## 2. Five prompt lines that stop Claude writing a fluffy README

```
Paste: No emojis. Do not use the words powerful, blazing, effortless, robust or lightweight.
```

## 3. Five prompt lines that stop Claude writing a fluffy README

```
Paste: Sections in this order: Install, Use, Options, Limits. Nothing else. Under 200 words.
```

## 4. Five prompt lines that stop Claude writing a fluffy README

```
Paste: Do not invent features, numbers or a license. If something is missing, write TODO.
```

## 5. Five prompt lines that stop Claude writing a fluffy README

```
Paste the README and your facts back in: List every sentence you cannot trace to these facts, one line each.
```

## 6. A four-beat Short script prompt (paradox, tension, pivot, twist) with a real Claude run on

```
Write a short video script about: [topic]. Use exactly 4 lines, in this order.
PARADOX: an opening line that seems impossible.
TENSION: two or three specific details, quickly.
PIVOT: starts with 'You see,' and explains why.
TWIST: one last line that changes how the viewer sees it.
Use only the facts I give you. Do not add numbers or claims of your own.
```

## 7. A four-beat Short script prompt (paradox, tension, pivot, twist) with a real Claude run on

```
PARADOX: The politest email in your outbox can be the hardest one to answer.
TENSION: Sorry to bother you. I just wanted to check. I think maybe. Three lines in, and the reader still has no idea what you want.
PIVOT: You see, every softener tells the reader this message is a burden.
TWIST: Put the ask in line one, and the sorry has nothing left to do.
```
